KEYSA AMANDA — PORTFOLIO WEBSITE

Desain versi 2: tanpa foto, dengan layout editorial, aksen biru, panel informasi,
timeline pendidikan, pengalaman kerja, keahlian, dan kontak.

Teknologi:
- HTML: struktur dan konten
- CSS: layout, warna, tipografi, dan responsive design
- JavaScript: menu mobile dan tahun otomatis

MENJALANKAN:
1. Ekstrak ZIP.
2. Buka folder di Visual Studio Code.
3. Klik kanan index.html > Open with Live Server.
4. Jika tidak ada Live Server, buka index.html langsung di browser.

PUBLISH:
Upload seluruh isi folder ke repository GitHub. Untuk GitHub Pages,
buka Settings > Pages > Deploy from a branch > main > /(root) > Save.

Periksa data kontak dan tambahkan link GitHub/CV serta proyek nyata jika tersedia.
