KEYSA AMANDA — PORTFOLIO WEBSITE

Teknologi:
- HTML: struktur dan konten
- CSS: layout, warna, tipografi, dan responsive design
- JavaScript: menu mobile dan tahun otomatis

MENJALANKAN:
1. Ekstrak ZIP.
2. Buka folder di Visual Studio Code.
3. Klik kanan index.html > Open with Live Server.
4. Jika tidak ada Live Server, buka index.html langsung di browser.
