Portfolio Website — Keysa Amanda

Website portofolio interaktif dan responsif yang dibangun untuk menampilkan latar belakang pendidikan, keahlian teknis, dan pengalaman kerja.

🚀 Fitur Utama
- UI/UX Modern & Dark Theme: Desain clean dengan aksen warna cyan dan efek glow.
- Fully Responsive: Tampilan optimal di semua perangkat (Mobile, Tablet, Desktop).
- Interaktif: Mobile menu navigation, scroll-reveal animation, dan dynamic year update.

🛠️ Bahasa & Teknologi yang Diterapkan
Sesuai dengan rubrik penilaian:
1. HTML5: Penataan struktur dokumen dengan semantic tags.
2. CSS3: Layouting dengan Flexbox & Grid, CSS Variables, dan animasi kustom.
3. JavaScript (ES6+): Interaktivitas DOM, Intersection Observer API, dan event listener.
4. Python: Script pembantu `analytics.py` untuk pemrosesan data analitik profil/keahlian.
5. Git & Development: Version control menggunakan Git, GitHub repository, dan live deployment via Vercel/GitHub Pages.
